# OSINT INTELLIGENCE — منصة الاستخبارات مفتوحة المصدر

> منصة تحليل وربط المعلومات الرقمية مفتوحة المصدر — محرك بحث متعدد المصادر،
> قاعدة بيانات استخباراتية، خريطة علاقات تفاعلية، ومركز أدوات سيبرانية.

---

## 1. ما تم تنفيذه فعليًا

| الوحدة | الحالة | ملاحظات |
|---|---|---|
| مخطط قاعدة بيانات كامل (28 جدولًا) | ✅ يعمل | SQLite افتراضيًا، فارغ للترقية إلى PostgreSQL |
| المصادقة والصلاحيات (RBAC + جلسات + CSRF) | ✅ يعمل | PBKDF2-HMAC-SHA256، 3 أدوار و12 صلاحية |
| محرك البحث `OSINT Search Engine` | ✅ يعمل | تنفيذ متوازي، نتائج تدريجية، إلغاء، احترام الفشل الجزئي |
| بنية الموصلات (Connectors) | ✅ يعمل | 8 موصلات حقيقية + إمكانية الإضافة |
| قاعدة البيانات الاستخباراتية | ✅ يعمل | رفع CSV/JSON/JSONL/TXT/XLSX/ZIP، معاينة، مطابقة أعمدة، كشف تكرار |
| ربط الكيانات + خريطة العلاقات | ✅ يعمل | محرك `Entity Resolution` + رسم Canvas تفاعلي |
| مركز الأدوات السيبرانية | ✅ البنية تعمل | التنفيذ المباشر يتطلب تثبيت الأدوات على المضيف |
| اكتشاف أدوات GitHub | ✅ يعمل | عبر GitHub REST API |
| التقارير والتصدير (JSON/CSV/PDF-HTML) | ✅ يعمل | مع حماية CSV و تنبيه حدود البيانات |
| الأمان (SSRF, XSS, CSRF, Rate limit, Path traversal) | ✅ يعمل | موثّق أدناه |
| سجل التدقيق | ✅ يعمل | لا يسجّل أسرارًا أو كلمات مرور |

> **لا يوجد أي رقم تجريبي ثابت في الواجهة.** كل الإحصاءات والنتائج تُقرأ من قاعدة البيانات الحقيقية.
> المصادر غير المهيّأة تظهر بوضوح كـ«غير مهيأة» بدل اختلاق نتائج.

## 2. لماذا Python + SQLite بدل Next.js + PostgreSQL؟

بيئة التشغيل الحالية (Termux / Android، ARM64) لا تدعم:
Node.js (أول الأمر غير مثبت)، PostgreSQL (بناؤه هشّ)، Redis، وDocker/الحاويات (بدون root).

لضمان **تطبيق يعمل فعليًا دون أعطال تثبيت**، بُني التطبيق بـ:
- **Backend:** Python 3 فقط (مكتبة قياسية: `http.server`, `sqlite3`, `hashlib`, `zipfile`).
- **Frontend:** HTML/CSS/JS خالص بلا build step (RTL داكن).
- **DB:** SQLite (قابل للترقية إلى PostgreSQL). مخطط الأسماء متوافق مع PostgreSQL.

يمكن نشر نسخة إنتاج على PostgreSQL + Nginx + gunicorn/uvicorn دون تغيير منطق العمل.

## 3. التثبيت والتشغيل

### على Termux
```bash
pkg install -y python git        # Python ≥ 3.10
cd osint-intelligence
python run.py --host 127.0.0.1 --port 8787
```

### على أي نظام آخر
```bash
python3 run.py --port 8787
```

ثم افتح: `http://127.0.0.1:8787`

**بيانات الدخول الافتراضية** (تُنشأ تلقائيًا في أول تشغيل فقط):
```
المستخدم: admin
كلمة المرور: ChangeMe_Admin1
```
> ⚠️ غيّرها فورًا. لإنشاء مستخدم جديد افتح: `الإدارة → مستخدم جديد`.

متغيرات البيئة الاختيارية: `OSINT_HOST`, `OSINT_PORT`, `OSINT_ENV`,
`OSINT_MAX_UPLOAD`, `OSINT_SESSION_TTL`, `OSINT_TOOL_MAX_CONCURRENCY`, `OSINT_APP_SECRET`.

## 4. إعداد قاعدة البيانات

- تُنشأ تلقائيًا عند أول تشغيل في `data/osint.db` مع كل الجداول والفهارس والبذور
  (`role`/`permissions`/المصادر/الأدوات) عبر نظام ترحيلات `app/schema.sql`.
- **نسخ احتياطي:** أوقف الخادم ثم انسخ الملفين `data/osint.db` و`data/osint.db-wal`.
  ```bash
  cp data/osint.db data/osint.db.bak
  ```
- **استعادة:** أوقف الخادم ثم استبدل الملفات.
- **PostgreSQL (إنتاج):** نفس أسماء الجداول؛ أنّشئ المخطط مكافئًا واستخدم
  `sqlalchemy`+`psycopg` (انظر `requirements-optional.txt`). لا أسرار مكتوبة في الكود.

## 5. إضافة مفاتيح API

المفاتيح تُخزّن **على الخادم فقط** في `data/secrets.json` (صلاحيات 0600) ولا تظهر أبدًا في الواجهة.

- عبر الواجهة: `المصادر والموصّلات → مفتاح` لحفظ مفتاح المصدر.
- أو عبر متغير بيئة: `export GITHUB_TOKEN=ghp_...`.

| المصدر | المفتاح | الأثر |
|---|---|---|
| GitHub | `GITHUB_TOKEN` | رفع حد الطلبات من 60/ساعة إلى 5000/ساعة |

بقية المصادر المفعّلة **لا تحتاج أي مفتاح**.

## 7. ميزات تحتاج إعدادًا خارجيًا

- **تنفيذ الأدوات السيبرانية (nmap, tshark, nuclei...):** تعمل البنية كاملة، لكن
  الأدوات نفسها غير مثبتة على هذه البيئة. ثبّتها (`pkg install nmap` …) ثم
  `مركز الأدوات → فحص حالة التثبيت`. الأدوات غير القابلة للتنفيذ هنا تظهر
  «تحليل/استيراد فقط» بوضوح ولا يُدّعى أنها تعمل.
- **PostgreSQL/Redis/상وازي الحاويات:** غير مدعومة على Termux.
- **البحث العكسي عن الصور:** يتطلب خدمة خارجية رسمية.
- **تحليل EXIF/OCR:** مخطط له عبر ExifTool عند تثبيته (الصور المدعومة عبر الأدوات).

## 8. ضوابط الأمان المطبّقة

- تخزين كلمات المرور عبر PBKDF2-HMAC-SHA256 (لا نص صريح).
- جلسات بعناصر عشوائية في كوكي `HttpOnly` + `SameSite=Lax`.
- حماية **CSRF** لكل الطلبات المُعدِّلة (هدر `X-CSRF-Token`).
- **SSRF guard**: حظر loopback/الشبكات الداخلية/`169.254.169.254` لجميع الطلبات والفحوص.
- **XSS**: تهريب كل المخرجات في الواجهة + سياسة `Content-Security-Policy` صارمة.
- **Path traversal**: منع الوصول خارج مجلد الملفات الثابتة.
- **Upload safety**: قائمة امتدادات مسموحة، فحص المحتوى الفعلي (MZ/ELF/shebang)،
  فحص محتويات ZIP، حد أقصى للحجم.
- **CSV Formula Injection**: تحييد الخلايا التي تبدأ بـ `= + - @`.
- **Rate limiting** لكل مسار (login/search/tool/upload).
- **Allowlisted tool exec** + قائمة أهداف مصرّح بها + مهلة زمنية + حدود تزامن.
  لا وجود لأي تنفيذ shell عشوائي من مدخلات المستخدم.
- **سجل تدقيق** لكل الإجراءات الإدارية دون تسجيل أسرار.

## 11. الحدود والأخلاقيات

- المنصة **للبحث في المصادر العامة المصرّح بها فقط** ولا تدّعي البحث في «كل الإنترنت».
- لا تجمع كلمات مرور مسروقة أو رموز جلسات أو بيانات اعتماد، وترفض استيرادها.
- النتائج المحتملة تُعرض منفصلة عن المؤكدة، مع تنبيه أن الاستنتاج الآلي ليس حقيقة.
- الموقع الجغرافي لعنوان IP تقريبي ولا يمثّل موقع شخص.
